# power-bi-projects
Power BI Projects | Data Analytics Portfolio

A collection of Power BI dashboard projects developed while learning data analytics, focusing on data transformation, visualization, and business insights.

🛠️ Tools & Technologies

- Microsoft Power BI Desktop
- Power Query for data cleaning and transformation
- DAX for measures and calculations, where applicable
- Data visualization and interactive dashboards

📊 Projects

1. Sales Data Analysis

Objective: Explore sales performance and identify trends using interactive visualizations.

Focus areas:

- Sales and order analysis
- Trends over time
- Business performance indicators

Skills demonstrated: Data preparation, KPI visualization, and dashboard design.

2. Insurance Data Analysis

Objective: Explore insurance-related data through an interactive dashboard.

Focus areas:

- Policy and customer metrics
- Premium and claims analysis, where supported by the dataset
- Comparisons across available categories

Skills demonstrated: Data modeling, data visualization, and business reporting.

3. UPI Transactions Data Analysis

Objective: Analyze UPI transaction data to explore transaction patterns and trends.

Focus areas:

- Transaction trends over time
- Payment methods and transaction categories
- Comparisons across available customer or transaction attributes

Skills demonstrated: Data transformation, interactive reporting, and visual analytics.
